# Liste et organisation des ressources matérielles, humaines et logicielles

## Ressources humaines

Chaque membre de l'équipe est développeur, tout le monde fait du code (pas nécessairement le même code).

## Ressources matérielles

Chaque développeur utilise son ordinateur personel pour coder, pour prendre des notes lors d'une réunion client ou rédiger le compte-rendus de la réunion client.

## Ressources logicielles

- Unity est utilisé pour le jeu et l'interface.
- Canva est utilisé pour les slides de réunions.
- Jira est utilisé pour les tickets.
- Github est utilisé pour le versionnement du code.
- Python est utilisé pour l'API entre l'interface et le backend.
- MinIO est utilisé pour stocker les musiques.
- PostgreSQL est utilisé pour stocker les informations utilisateurs.
- Celery est utilisé pour effectuer les travaux lourds (génération de niveaux).
- Redis est utilisé pour gérer les travaux lourds.
