# Protocole de tests
Il a été convenu que le test se déroulerait en 3 parties:

- Avant le test, l'utilisateur répondra à des questions pour dresser un profil utilisateur, et répondra à des questions pour faire de la veille concurentielle
- Pendant le test, le membre de l'équipe renseignera ce qui à été fait pendant le test pour s'assurer que tout se passe bien
- Après le test, l'utilisateur indiquera son ressenti sur le jeu en répondant à des questions
